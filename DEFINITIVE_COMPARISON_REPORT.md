## 1. EXECUTIVE SUMMARY

### 1.1 Market Positioning Statement
> **CPSL v0.9.0 is the only platform that combines WKO5-level analytical depth (3P power-duration modeling, phenotype radar, breakthrough detection) with Xert-style adaptive planning (6 methods × 8 goals), Ride Cave-style phase detection, AND an open API-first architecture — all at a one-time cost model with full data ownership.**

### 1.2 Competitive Landscape Segmentation

| Segment | Tools | Core Philosophy |
|---------|-------|-----------------|
| **Deep Analytics (Desktop/Pro)** | WKO5, Golden Cheetah, CPSL | Mathematical modeling, phenotype, custom charts |
| **Adaptive Training Ecosystems** | Xert, TrainerRoad, Ride Cave | Daily recommendations, workout execution, trainer control |
| **Metabolic/Lab-Grade** | INSCYD | VLamax, FatMax, lactate kinetics, coach-gated |
| **Data Platforms (Web/API)** | Intervals.icu, TrainingPeaks, Strava | Aggregation, social, basic analytics, API |
| **Virtual Riding** | Zwift, Rouvy, TrainerRoad | Gamified training, structured workouts |
| **Race/Pacing Optimization** | Best Bike Split, MyWindSock, VeloViewer | Course-specific, aero, prediction |
| **CPSL v0.9.0** | **Hybrid: Analytics + Adaptive Planning + Open Architecture** | **Unique combination** |

### 1.3 CPSL v0.9.0 Unique Value Propositions

| # | Differentiator | Competitor Benchmark |
|---|----------------|---------------------|
| 1 | **6 Phenotype Classes** (vs WKO5's 4, Ride Cave's 6) | Most granular rider classification |
| 2 | **Formula Alert Engine** (7 operators, streaks, 23 metrics) | Unmatched customization |
| 3 | **6 Training Methods × 8 Goals** in Adaptive Planner | Xert: 1 method; TrainerRoad: AI-only; Ride Cave: auto only |
| 4 | **3P Power-Duration Model** with R², tau, TTE, curve points | Matches WKO5 V2; exceeds Xert (MPA only) |
| 5 | **Breakthrough Detection** (Xert-style MPA + signature estimation) | Parity with Xert; exceeds WKO5 |
| 6 | **Durability Score** (fresh vs tired >2h rides) | Unique implementation |
| 7 | **API-First + .zwo + FIT + Local Data** | Intervals.icu has API; WKO5 is desktop-only; TrainerRoad is closed |
| 8 | **One-Time / Self-Hosted Cost Model** | vs $21-25/mo (TR/Xert) or $169 (WKO5) |

### 1.4 Remaining Critical Gaps (v0.10.0 Roadmap)
1. **Real smart trainer control** (ANT+ FE-C / BLE FEC) — currently simulated
2. **Native mobile apps** (iOS/Android) — currently responsive web only
3. **Coach-athlete workspace** — no multi-athlete management
4. **Course-specific pacing** (Best Bike Split integration)
5. **Metabolic profiling** (VLamax/FatMax via INSCYD partnership)
